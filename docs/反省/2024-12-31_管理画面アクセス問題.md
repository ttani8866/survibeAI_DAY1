## 根本原因（真因）

### コードの問題
```javascript
// ❌ 問題のあったコード
async jwt({ token, user }) {
  if (user?.email) {
    const dbUser = await User.findOne({ email: user.email });
    if (dbUser) {  // ← DBアクセス失敗時はここに入らない
      token.role = isAdmin ? "admin" : "user";
    }
  }
  return token;  // ← roleが未設定のまま返される
}

// ✅ 修正後のコード
async jwt({ token, user }) {
  if (user?.email) {
    // DB接続の有無に関わらず必ずroleを設定
    const isAdmin = adminEmails.includes(user.email?.toLowerCase() || "");
    token.role = isAdmin ? "admin" : "user";
    
    // DBアクセスは後から（失敗しても続行）
    try {
      const dbUser = await User.findOne({ email: user.email });
      if (dbUser) {
        token.id = dbUser._id.toString();
      }
    } catch (error) {
      console.error("JWT callback DB error:", error);
    }
  }
  return token;
}
```

### 環境の問題
- MongoDB AtlasのIPアクセスリストに `0.0.0.0/0` がなかった
- Vercelからの接続がブロックされていた
